# 😷 Face Mask Detection Using CNN

Welcome! This project is my **first hands-on AI/ML project** — a Face Mask Detection model built using **Convolutional Neural Networks (CNNs)**, trained on a real-world dataset to classify:

- Mask Worn Properly
- Mask Worn Improperly
- No Mask

While the model is trained on a minimal dataset, it's a solid step into the world of deep learning and computer vision.

---

## 🚀 What This Project Includes

- 📊 **Image Preprocessing** and Augmentation
- 🧠 **CNN Model** built from scratch with TensorFlow/Keras
- 🎯 **Model Training** and Validation
- 💻 **Real-time Webcam Inference**
- 🌐 (Coming Soon) Flask API for frontend integration

---

## 🛠 Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- Jupyter Notebooks
- Kaggle (for training & experimentation)

---
## ⚠️ Limitations

This was built using a **limited dataset**, so real-world accuracy may vary.  
But hey — this is just **step one**, and it works! 🎉
